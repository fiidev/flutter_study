# Study - Flutter Learning Journey

## Overview

This repository serves as a personal learning log documenting my journey in mastering the **Dart programming language** and the **Flutter framework**. It contains a curated collection of exercises, mini-projects, and experiments built while developing proficiency in cross-platform mobile and web application development.

The primary goal of this project is to build a strong foundation in Flutter's core concepts — including widget composition, state management, navigation, and responsive UI design — through consistent, hands-on practice rather than passive learning.

## Objectives

- Understand Dart fundamentals, including syntax, null safety, and asynchronous programming
- Explore Flutter's widget tree and declarative UI paradigm
- Practice implementing common design patterns and clean architecture principles
- Gain experience with state management solutions (e.g., Provider, Riverpod, Bloc)
- Build and deploy cross-platform applications from a single codebase

## How to Run

### Prerequisites

- Flutter SDK stable (project uses `sdk: ^3.12.2`)
- One of the following targets: Android Studio / Xcode / Chrome

### Setup

```bash
git clone https://github.com/fiidev/flutter_study.git
cd flutter_study
flutter pub get
```

### Run

```bash
flutter run                # select device when prompted
flutter run -d chrome      # example: web (Chrome)
```

### Test

```bash
flutter test
```

### Build (optional)

```bash
flutter build apk
```
